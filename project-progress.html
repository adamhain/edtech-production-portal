About This Data
  • Source: the Summary tab of the "Production_Task_Trackers_Master" Google Sheet, which aggregates every per-task tracker into one row per project.
  • Not live-synced. It's a manual point-in-time snapshot (same as Equipment Orders and Production Archive Status) — re-pulled by re-running the build after the Sheet changes, not on page load.
  • Percentages are recomputed from the completed/total task counts rather than read from the Sheet, so a stale percentage cell can't disagree with the counts shown here.
  • "not linked" means no Slack List URL is on file for that tracker yet — the progress numbers are still real. Ask Adam to add the link and it becomes clickable on the next build.
  • Task-level detail (assignee, due date, workflow phase) lives in each project's Slack List, not here — this page deliberately stops at per-project counts.
