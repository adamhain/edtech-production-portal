Per-Project Production Trackers (Slack Lists)

Every trackable list in this system is a Slack List. Adam or the Production Lead builds one out for every shoot/project — for series with a lot of episodes (e.g. the Learning Lab podcast), there's a "list of lists" so each episode gets its own tracker without one giant list getting unwieldy.

1. Grouping — flexible, changeable anytime

By default, items are grouped by production/workflow phase. You can instead group by global phase (pre-production vs. post), by due date, or by assignee — whatever view is most useful in the moment. As the trackers get more granular over time, items will also carry real assignees rather than just being checked off in bulk once a phase is known to be done.

2. View a specific project as a channel tab

If you're working on one project — say Studio Promo — its tracker typically gets pinned as a tab right in that project's channel, so you can see at a glance how much has been completed. (For series with a lot of episodes/lists, this doesn't always fit as individual tabs — see the "list of lists" pattern above.)

3. Feeds the master data pipeline (Irina / Tableau)

Each tracker is connected via a Slack workflow that sends its data to a second list, structured with a bunch of extra variables. That second list is what gets sent to Irina for processing and into Tableau for reporting — it captures information that can't be pulled from the downloaded tracker CSVs alone. In other words: the per-project tracker isn't just a to-do list, it's also the source data for studio-wide reporting, which is exactly why it's set up the way it is.

Finding What's Assigned to You
Slack → Lists

Open the Lists section in Slack to see every list you have access to. Because Adam or the Production Lead builds so many of these, that view can get long — narrow it with Shared with You (lists someone else created and gave you access to) or the lists you created yourself.

Assigned to You — the useful one

This view pulls together everything assigned to you across every list, regardless of which project it belongs to — no need to check each tracker individually. Works the same way in the Slack mobile app, so you can check what's on your plate without opening a laptop.

Found something stale?

If you spot an item in your assigned view that's out of date — wrong due date, already done, etc. — either update it yourself or flag it to Adam. This is a known rough edge as these trackers get used more heavily.

Studio Sub-Project & Virtual Production Tracker

This is a separate list, living in the studio channel, for studio sub-projects and virtual production work — things that aren't tied to one specific shoot. Unlike the per-project trackers above, items here aren't in any particular order; the production workflow tracker is meant to be linear, this one isn't.

1. Tracked at the item level

Click on any item to open its detail card — fields, notes, everything about that one item live there. It's easier to work with these items in Board (Block) view rather than the default list view.

2. A custom "subproject" field powers the grouping

The fields on each item connect back to that same master list/pipeline described above, pulling data from it. Grouping-by-category (like "filter by project" here, or "filter by workflow name" on the per-project trackers) is created with a selection field — a categorical/distinct-value field. In this tracker, that field is called subproject, pre-loaded with the current studio sub-projects. You can add new subprojects to the list, delete ones that no longer apply, or even create entirely new custom fields to group by however makes sense for you.

⚠️ Don't delete the existing fields on sub-project tracker items (even if you're not using one). They're wired to the master spreadsheet the rest of the reporting pipeline depends on — deleting a field breaks that connection, not just the view.
