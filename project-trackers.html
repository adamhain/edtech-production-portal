How-to

Project trackers.

Every project has its own Google Sheet checklist, from scheduling to archiving. This page covers how to use it.

Find your tracker
The link is pinned in your project's Slack channel. Open it while you're signed in to Google with your Stanford account, so the tracker knows who ticked what. Can't open it? Ask Adam for access.
Day to day
  1. Tick Done when a task is finished. Done on and Done by fill in automatically. Untick it if you ticked it by mistake.
  2. Set the Owner: type the name of whoever is doing the task.
  3. Adjust Start and Due / End if the plan changes. They're pre-filled from the shoot and delivery dates, and you can type over them. A red Due / End means it falls before Start.
  4. Use Notes and Link for anything the next person needs, like a quick note, a folder, or a cut to review.
  5. Check the Timeline tab for a Gantt view of the whole project. It updates itself, so change dates on the Tracker tab.
Good to know
  • See a "Filled in automatically" warning? That's OK. You clicked a cell the tracker fills in for you (like Status or Done by). It's only a warning: click OK to carry on, or Cancel to leave it alone.
  • Slack Lists are retired. Please don't update the old Slack List trackers. The Google Sheet is the only tracker now.
  • Progress shows up on the portal. The Project Progress page reads every tracker twice a day on weekdays.
  • Need something bigger? For a new project, a missing task, or a change to how the tracker is set up, ask Adam.
Please don't
These break the automatic progress reading
  • Rename, move or delete the tracker file.
  • Rename, delete or reorder its tabs (Tracker, Timeline, Deliverables & specs).
  • Delete task rows. If a task doesn't apply to your project, ask Adam and he will remove it.
  • Make your own copy to work in. Keep one tracker per project.
