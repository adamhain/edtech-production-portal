IngestMaster

Raw footage → Resolve-ready.

A tool that takes a raw camera/audio ingest folder and turns it into an organized, Resolve-ready project — automatically. No Terminal required.

IngestMaster video ingest pipeline

🧪 Currently being tested — and so far only confirmed to work on macOS. Treat it as a beta tool: watch the log while it runs, and don't assume a result is correct without checking Resolve afterward.
What It Does

You point it at a folder of raw footage. It runs 5 steps in order:

1. Organize files

Sorts everything into Camera/, Audio/, and Garbage/ inside your chosen output folder. It figures out which audio files are real mics (checks the filename and confirms there's actual signal, not just silence) vs. camera audio tracks, mic/RCA scratch tracks, and switcher junk.

2. Confirm audio

Lists what was kept and what it's about to do next.

3. Convert to mono

Each stereo audio file gets split into Left and Right mono tracks. Whichever side actually has your mic on it stays in Audio/; the silent side goes to Audio/Garbage/. The original stereo files are kept in Audio/Originals/.

4. Build the Resolve project

Creates a new DaVinci Resolve project, imports everything into Camera and Audio Mono bins, and auto-syncs audio to camera clips by timecode.

5. Trigger transcription

Attempts to kick off Resolve's transcription via its API. This mostly doesn't work yet (see Limitations) and prints manual steps instead.

✅ Nothing is ever deleted. "Garbage" just means a subfolder — camera audio tracks, silent mic channels, switcher junk, all of it is moved there, never sent to the Trash. If the tool ever files something wrong, it's still on disk and recoverable.
How to Use It
1. Open the app

Double-click launch_ingest_master.command in the IngestMaster folder (or it may already be running).

2. Ingest Folder

Drag your raw footage folder onto the field, or click Browse.

3. Output Folder

Drag or Browse to a folder where you want the organized result to land. This can be a new empty folder anywhere with enough free space — it doesn't need to exist yet if using Browse's "New Folder" option.

4. Project Name

Type a name for the new DaVinci Resolve project it'll create.

5. "Skip Resolve steps" checkbox

Leave it unchecked if DaVinci Resolve Studio is open and ready to go. Check it if you just want the files organized and converted, without touching Resolve at all.

6. Run

Click Run Pipeline and watch the log. The llama munches hay while it works. When it's done, the log says so and the llama goes back to idle.

7. Check Resolve

Open the new project. If it was a multicam shoot, the log will print exactly which clips belong together per take — that part still has to be done by hand (see Limitations below).

If something's wrong before it even starts

The llama goes puzzled and the log shows a warning at the top. Read that before assuming it's broken — usually it just means a field was left blank or a folder wasn't found.

Limitations
  • Multicam clips aren't created automatically. DaVinci Resolve's scripting API has no function for building a multicam clip — that's a Resolve-UI-only feature. The tool auto-syncs audio to each camera angle by timecode, then prints a per-take instruction list (which clips to Ctrl-click, then "Create New Multicam Clip Using Selected Clips" in Resolve) for you to do manually. Takes about a minute per take.
  • Transcription is mostly manual too, for the same reason — Resolve's API doesn't yet expose full transcription controls. The tool documents the manual steps in the log rather than pretending it did it for you.
  • Requires DaVinci Resolve Studio (the paid version — the free version has no scripting API) already open, with Preferences > General > External scripting using set to "Local network." Steps 4 and 5 will fail with a clear error if Resolve isn't running.
  • Built around MADI-style audio naming. It looks for filenames containing "MADI {number}" and auto-detects however many MADI channels are actually present in your footage — works whether a take used 2 mics or 14. A different mic/interface naming scheme would need a script tweak.
  • All camera angles land in one Camera bin, not separated by camera number — Resolve's multicam step (above) is what actually organizes by angle.
  • It reorganizes what's already on your drive — it is not a backup. Keep your normal backup process in place regardless.
  • The app doesn't save its log to disk. If a run does something unexpected, screenshot the log or note what it said before closing the window — there's currently no way to recover it afterward.
  • Needs ffmpeg installed on the machine (for audio analysis/conversion) — the launcher will tell you if it's missing.
Quick Troubleshooting
SymptomLikely Cause
Llama goes puzzled immediately A required field was blank, or the folder path didn't resolve — check the log's warning line
Output folder stays empty after clicking Run Same as above — the run never actually started; re-check Ingest/Output/Project Name fields
Step 4/5 fail with a connection error DaVinci Resolve Studio isn't open, or External Scripting isn't enabled in Preferences
A mic you expected is missing from Audio/ Check Garbage/ and Audio/Garbage/ — it's very likely there, just flagged as silent on that channel
