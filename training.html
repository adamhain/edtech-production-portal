01
Director
Creative vision · Shot calling · Talent direction · Client communication
YouTubeLinkedIn Learning
⌄

The Director holds creative and logistical authority over the entire shoot. They are the primary decision-maker on set and the main point of contact for communicating the client's vision to the crew.

Meet with the client before the shoot to understand goals, tone, and key messages
Create or review the shot list and communicate it clearly to all crew before call time
Run the pre-shoot briefing, assigning each crew member their role
Call every shot during the shoot: angles, takes, retakes, pacing, and talent direction
Monitor the program monitor throughout to evaluate framing, lighting, and audio
Manage time on set actively — keep the shoot moving and flag if schedule slips
Conduct a post-shoot debrief with the client to confirm deliverables
Review rough edit before delivery and provide clear notes to the editor

02
First Engineer
Technical Director · Blackmagic ATEM · Audio monitoring · System ops
YouTubeLinkedIn LearningGear
⌄

The First Engineer is the hands-on operator of the Blackmagic ATEM switcher and the central technical authority on set. They ensure all systems are recording, all signals are clean, and all technical issues are caught in real time.

Arrive early to power on and test all systems before the crew arrives
Run pre-shoot system check: camera feeds, audio meters, HyperDeck armed
Operate the ATEM switcher in real time on the Director's calls
Monitor all audio levels continuously and flag any clip or dropout
Confirm recording has started before every take
Troubleshoot signal loss, audio dropout, or switcher issues in real time

03
Remote QC Engineer
Program output monitoring · Audio QC · Timecode logging · Zoom monitoring
YouTube
⌄

The Remote QC Engineer monitors the composited program output from a separate location in real time via Zoom, connected to the ATEM HD8 ISO via USB. They are the last line of defense before footage is recorded.

Monitor the full program output throughout the entire shoot
Watch multiview feed showing all camera channels simultaneously
Monitor audio waveforms and VU meters — flag any clip or dropout via IFB
Log every flagged issue with the timecode it occurred at
Verify HyperDeck recording status is active during all takes
Deliver written QC log to editor within 1 hour of wrap

Script Supervisor
Continuity · Take tracking · Timing · Editor notes
YouTubeLinkedIn Learning
⌄

The Script Supervisor maintains continuity, tracks good takes, times scenes, and provides detailed notes to the editor.

Time scenes to match client requirements
Document ad-libs or script changes in real time
Provide detailed notes to the editor for post-production

DMX controllers · Studio lighting · Flare prevention · Setup & breakdown

⌄

The Lighting role adjusts and operates studio lights to match the client's desired look, using DMX controllers and monitoring the program output to ensure lighting reads correctly on camera.

Ingest / Footage Wrangler
Footage copying · Backups · DaVinci Resolve · Proxies · Multicam sync
YouTube
⌄

The Ingest/Footage Wrangler copies all footage to the production server, creates backups, sets up DaVinci Resolve Cloud projects, and prepares multicam clips for the editor.

Copy all footage and audio to production server immediately after shoot
Back up dailies to drives and cloud
Set up DaVinci Resolve Cloud project
Ingest footage and create proxies for editing
Set up multicam clips and sync for editing
Ensure naming conventions are followed throughout
